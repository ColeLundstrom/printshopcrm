# Free software, optional hosting

PrintShopCRM is a community project for print shops. The complete application is available under
[AGPL-3.0-or-later](LICENSE). Hosted and self-hosted shops use the same code, features, and unlimited seats.

## Run it yourself

The software has no subscription or license fee. [INSTALL.md](INSTALL.md) covers installation,
backups, updates, and recovery. You control the server and your data. Contributions, bug reports,
workflow feedback, and documentation improvements are welcome through [CONTRIBUTING.md](CONTRIBUTING.md).

## Let MerchTroop run it

Voluntary [project support](docs/PROJECT-SUPPORT.md) helps fund maintenance and contributors.
It is separate from a hosting subscription and does not change software access or hosting terms.
You can use every feature without contributing.

The optional paid service covers **hosting on our server and basic setup**: shop identity, users,
and the starting configuration. You are paying for operating the installation, not access to
features or a different edition of the software.

Your shop remains responsible for checking its pricing, tax settings, and imported records before
using them with customers. Large migrations, custom integrations, and bespoke development are not
included in basic setup. There is no promise of unlimited consulting or a particular response time.

Hosting prices and any one-time setup charge are confirmed before service starts. Existing hosting
agreements remain unchanged. No payment is needed to download or run the software yourself.

An interrupted hosting checkout can be resumed from **Hosting**. See
[checkout recovery](docs/HOSTING-CHECKOUTS.md) for owner controls and operator payment reviews.

The full database exports as one JSON file from Settings; customer, quote, invoice, payment,
job, artwork history, and timeline CSV exports are also available. You can export your records or request your shop's database and artwork to move elsewhere. There
is no export charge. Payment processors, email, SMS, domains, and other external services can have
their own charges; those are not software license fees.

## Community and ownership

The project earns its place by being useful and dependable. Improvements go through automated
checks and review, then versioned releases with backup and rollback procedures. See
[GOVERNANCE.md](GOVERNANCE.md) and [RELEASING.md](RELEASING.md).

We are not offering a separate proprietary edition or selling commercial license exceptions as
part of this service. The license in [LICENSE](LICENSE) remains unchanged.

For hosting and setup: [printshopcrm.com](https://printshopcrm.com).
For self-hosting and contributions: [GitHub Discussions](https://github.com/ColeLundstrom/printshopcrm/discussions).
